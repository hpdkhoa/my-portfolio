# Benchmarks

This folder is where you drop the **actual measurement outputs** from your benchmark harness
once you export them — the recall-vs-latency tables, tokens/sec-vs-offload curves, and
compile-pass-rate-vs-quantization numbers referenced in the writeups.

Keep them as plain `.md` tables, `.csv`, or small `.png` charts. Do **not** put raw datasets,
embeddings, or the legal corpus here (the `.gitignore` blocks those by default).

Until you add real exports, the writeups describe the methodology and the shape of the results;
this folder makes the numbers themselves first-class and easy to point an interviewer at.


> `ENVIRONMENT.md` in this folder is auto-generated by `tools/fill_portfolio.py` — run it on the machine that hosts the private repos to capture GPU, models, and repo statistics.
