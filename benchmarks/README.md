# Benchmarks

Every number quoted in the writeups comes from a run recorded here.

`results/measured.json` holds the measured tables. It is written by the private
repos' own harnesses, never by hand:

- gen-system: `bench/summarise.py` aggregates the raw `genbench` runs under
  `results/<date>/raw/` into rows and merges them here.
- HieuLuat: the retrieval bench writes its rows the same way, one label per
  index configuration.

`tools/fill_portfolio.py` then renders those rows into the writeups between the
`<!--measured:...-->` markers. Nothing between those markers is typed by hand,
so a table in a writeup and the JSON here cannot drift apart.

Each table carries a `_provenance` block: the date, the source repo commit, the
frozen task set, and the GPU. Rows carry `n` and, where the harness measured
them, the min and max. A cell showing a dash means the harness did not measure that value. It is not a
rounded zero, and it is not a gap to fill in later by guessing.

`ENVIRONMENT.md` is generated by `tools/fill_portfolio.py` on the machine
that hosts the private repos, and records the GPU, driver, and installed models
the runs were taken on.
